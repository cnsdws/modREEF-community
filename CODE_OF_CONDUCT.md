# Community code of conduct

The modREEF community is committed to a respectful, inclusive, and technically
rigorous environment.

## Expected behavior

- Be constructive, specific, and patient.
- Critique ideas and evidence rather than people.
- Respect privacy, intellectual property, and hardware safety boundaries.
- Clearly distinguish verified behavior from inference.
- Help make participation accessible to people with different backgrounds and
  levels of experience.

Harassment, discrimination, threats, deliberate exposure of private data, and
unsafe or deceptive technical guidance are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainer through their
GitHub profile. Security vulnerabilities belong in GitHub private vulnerability
reporting instead. Reports will be reviewed confidentially and may result in a
warning, removal of content, or temporary or permanent exclusion from project
spaces.

This policy applies in repository discussions, reviews, project communication,
and public events where someone represents modREEF.
