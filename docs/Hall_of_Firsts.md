# Why modREEF Exists

Aquarists should think about living reefs...

—not outlets.

—not timers.

—not vendor lock-in.

—not controller programming.

Hardware should be interchangeable.

Software should understand intent.

Automation should be transparent.

Technology should disappear into the background so the aquarist can focus on the animals.
